# Teclas de Atalho do VS Code

## Geral

| Atalho | Descrição |
|--------|-----------|
| `Ctrl + Shift + P` | Abrir paleta de comandos |
| `Ctrl + P` | Abrir arquivo rapidamente |
| `Ctrl + ,` | Abrir configurações |
| `Ctrl + K  Ctrl + S` | Abrir atalhos de teclado |
| `Ctrl + Shift + X` | Abrir extensões |
| `` Ctrl + ` `` | Abrir/fechar terminal integrado |
| `Ctrl + Shift + N` | Nova janela |
| `Ctrl + Shift + W` | Fechar janela |

---

## Edição

| Atalho | Descrição |
|--------|-----------|
| `Ctrl + C` | Copiar linha (sem seleção) |
| `Ctrl + X` | Recortar linha (sem seleção) |
| `Ctrl + D` | Selecionar próxima ocorrência |
| `Ctrl + Z` | Desfazer |
| `Ctrl + Shift + Z` | Refazer |
| `Alt + ↑ / ↓` | Mover linha para cima/baixo |
| `Shift + Alt + ↑ / ↓` | Duplicar linha para cima/baixo |
| `Ctrl + Shift + K` | Deletar linha |
| `Ctrl + Enter` | Inserir linha abaixo |
| `Ctrl + Shift + Enter` | Inserir linha acima |
| `Ctrl + ]` | Indentar linha |
| `Ctrl + [` | Desindentar linha |
| `Ctrl + /` | Comentar/descomentar linha |
| `Shift + Alt + A` | Comentar bloco selecionado |
| `Ctrl + Shift + [` | Recolher bloco de código |
| `Ctrl + Shift + ]` | Expandir bloco de código |

---

## Navegação

| Atalho | Descrição |
|--------|-----------|
| `Ctrl + G` | Ir para linha |
| `Ctrl + Home` | Ir para o início do arquivo |
| `Ctrl + End` | Ir para o fim do arquivo |
| `Ctrl + ← / →` | Mover por palavras |
| `Ctrl + Shift + O` | Ir para símbolo no arquivo |
| `Ctrl + T` | Ir para símbolo no workspace |
| `F12` | Ir para definição |
| `Alt + F12` | Espiar definição |
| `Shift + F12` | Ver todas as referências |
| `Alt + ← / →` | Navegar no histórico (voltar/avançar) |
| `Ctrl + Tab` | Alternar entre arquivos abertos |

---

## Seleção

| Atalho | Descrição |
|--------|-----------|
| `Ctrl + A` | Selecionar tudo |
| `Ctrl + L` | Selecionar linha inteira |
| `Ctrl + Shift + L` | Selecionar todas as ocorrências |
| `Ctrl + F2` | Selecionar todas as ocorrências da palavra |
| `Shift + Alt + →` | Expandir seleção |
| `Shift + Alt + ←` | Retrair seleção |
| `Alt + Click` | Múltiplos cursores (inserir cursor) |
| `Ctrl + Alt + ↑ / ↓` | Inserir cursor acima/abaixo |

---

## Busca e Substituição

| Atalho | Descrição |
|--------|-----------|
| `Ctrl + F` | Buscar no arquivo |
| `Ctrl + H` | Substituir no arquivo |
| `Ctrl + Shift + F` | Buscar em todos os arquivos |
| `Ctrl + Shift + H` | Substituir em todos os arquivos |
| `F3 / Shift + F3` | Próxima/anterior ocorrência |
| `Alt + Enter` | Selecionar todas as ocorrências encontradas |

---

## Arquivos e Abas

| Atalho | Descrição |
|--------|-----------|
| `Ctrl + N` | Novo arquivo |
| `Ctrl + O` | Abrir arquivo |
| `Ctrl + S` | Salvar |
| `Ctrl + Shift + S` | Salvar como |
| `Ctrl + K  S` | Salvar todos |
| `Ctrl + W` | Fechar aba |
| `Ctrl + Shift + T` | Reabrir aba fechada |
| `Ctrl + 1 / 2 / 3` | Focar no grupo de editor 1/2/3 |
| `Ctrl + \` | Dividir editor |

## Formatação e Código

| Atalho | Descrição |
|--------|-----------|
| `Shift + Alt + F` | Formatar documento |
| `Ctrl + K  Ctrl + F` | Formatar seleção |
| `F2` | Renomear símbolo |
